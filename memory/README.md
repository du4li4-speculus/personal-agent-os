# Persistent Memory

This tree is reserved for explicitly reviewed and promoted reusable knowledge. Runtime does not write here. Promotion must preserve provenance, select exactly one owner scope, exclude student and other run-instance data, and be reviewed outside `AgentRuntime.run()`.

- `global/` owns reusable cross-Project rules and stable preferences.
- `projects/<project-id>/` owns one Project's reviewed decisions and history.
- `skills/<skill-id>/` owns reviewed domain edge cases and capability improvements.

Unreviewed observations remain proposed candidates inside their source run.
