# Roadmap

This file records planned capabilities. Planned items do not block completion of currently available stages.

## Next executable milestone

Create one Controller-led minimum loop:

1. Normalize the prompt and student response.
2. Produce traceable evidence.
3. Run the readiness gate.
4. Produce a structured six-dimension assessment from the scoring contract.
5. Return explicit completion, review-needed, or insufficient-evidence status.

## Later stages

- Evidence-linked diagnosis and revision priorities.
- Student rewrite loop and teacher override capture.
- Student, parent, and teacher report rendering from one validated result object.
- Grammar and sentence-building agents invoked by the Controller only when diagnosis identifies a relevant training need.
- End-to-end validation and registry activation.

Detailed future work belongs here rather than in the active execution path.
