# Projects

Tracked Project files contain non-sensitive declarative configuration only. A Project may select registered Skills plus upstream-approved Cognition and Memory policy modes; it cannot redefine Skill semantics, Registry truth, Cognition protocols, Core rules, or domain logic.

Run-instance inputs, source paths, identities, intermediates, reports, traces, and Memory Candidates belong under the ignored `runs/` boundary and must never be added here.
