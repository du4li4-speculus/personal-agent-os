# 诊断层

诊断把 assessment 中已经有证据的表现转成可教学的问题，不重新计算分数。输出必须符合 `schemas/diagnostic.schema.json`，每个 issue 都要回链 evidence ids。

## 能力层映射

| ability layer | 可吸收的既有评分信号 | 典型诊断方向 |
| --- | --- | --- |
| `task_response` | 切题、逐问覆盖、起点—终点、原创关键词语义云 | 漏任务点、只答起点、选项覆盖不足 |
| `organization` | 结构和逻辑、句子功能、连接率 | 信息顺序、指代回扣、句内结构或句间连接 |
| `language_control` | 语法、词汇和句型、搭配、语域 | 完整谓语、动词补语、搭配组块、正式度 |
| `reasoning` | 论证与理由、扩展和细节 | 机制层不足、结果层断裂、例子与论点脱节 |

## 诊断规则

- 优先选择最影响下一次表现的一个高优先级问题；不要把同一证据拆成重复问题。
- `confidence` 反映证据完整度，不是分数高低。
- 没有教师批注时，明确标记为 AI/自评来源；不得伪造教师判断。
- 教师覆盖另存为 `teacher_override`，诊断原记录和理由均保留；覆盖不会自动修改 rubric 或 runtime。
- 诊断只提出可验证的能力假设，不能由一次样本宣称长期趋势。
